# Покорми птенчика

Мини-игра: проведи птенчика к зерну по игровому полю 6×6. Ходить можно только на соседние клетки (вправо-влево-вверх-вниз), без диагоналей и перепрыгиваний.

## Требования для запуска

Нужен **Python 3.8+** и две библиотеки графики:

- **tkinter** — встроенная GUI-библиотека
- **Pillow** + **ImageTk** — для отображения рисунков птенчика и зерна

## Установка

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install python3-tk python3-pil.imagetk
pip install --user Pillow
```

### Windows

```bash
pip install Pillow
```

> Tkinter уже входит в стандартный установщик Python с официального сайта `python.org` (при установке оставить галочку «tcl/tk and IDLE»).

## Запуск

```bash
python3 pets/main.py
```

или из папки проекта:

```bash
cd pets
python3 main.py
```

## Изображения

В папке `images/` лежат файлы `chick.png` (птенчик) и `grain.png` (зерно).
Если их нет или нет Pillow — игра нарисует фигуры-заглушки автоматически.

## Управление

- Клик по соседней клетке — птенчик шагает туда.
- Ошибка при ходу не на соседнюю клетку — окно с предупреждением.
- Кнопка «Новая игра» — перезапуск с новым расположением зерна.
- Кнопка «Выход» — закрыть игру.

## Тесты

Автотесты лежат в папке `tests/`:
- `test_game.py` — юнит-тесты логики игры (не требуют графики, запускаются на любом компьютере).
- `test_gui_flow.py` — интеграционные тесты GUI-кейсов (требуют tkinter и дисплей).

Запуск всех тестов:

```bash
cd pets
python3 -m unittest discover -s tests -p "test*.py"
```

Запуск только тех, что не зависят от графики:

```bash
python3 -m unittest tests.test_game -v
```
